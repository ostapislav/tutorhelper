# TutorHelper — Backend-сервис для репетитора

**TutorHelper** — это сервис для автоматизации работы репетитора. Он помогает вести учёт учеников, составлять расписание, контролировать проведённые занятия и, самое главное, **автоматически считать долги по оплате**.

## Стек
Язык:	Java 17
Фреймворк:	Spring Boot 3.2.0
ORM:	Spring Data JPA / Hibernate
База данных:	PostgreSQL 15
Миграции:	Liquibase
Контейнеризация:	Docker, Docker Compose
Документация API:	Swagger / OpenAPI 3 (springdoc)
Сборка:	Gradle (Groovy)

## Возможности :
  Управление учениками: CRUD + поиск по телефону и ФИО.
  Расписание: Создание шаблонов занятий (день недели, время, длительность).
  Генерация расписания на неделю: Автоматический расчёт дат занятий на основе шаблонов.
  Занятия: Проведение занятий, привязка к расписанию, указание темы и стоимости.
  Финансы:
      Отметка оплаты с фиксацией даты платежа
      Автоматический расчёт долгов по каждому ученику (сумма + количество неоплаченных занятий).
